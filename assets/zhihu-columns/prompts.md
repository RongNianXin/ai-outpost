# 知乎专栏封面生图提示词

## 共用规格

- 用途：知乎专栏封面
- 画布：正方形，建议输出 1024×1024 PNG
- 系列关系：三张图采用同一套克制的科技媒体编辑视觉，像同一本杂志的三个栏目
- 共用要求：主体居中且占画面约 55%—65%，四周留出安全空间，缩小到 100×100 仍能辨认；不生成文字、字母、数字、品牌 Logo、水印、二维码、伪造界面或乱码
- 共用避雷：大面积黑色或深蓝背景、蓝紫霓虹、发光大脑、机器人头像、复杂电路、全息屏幕、赛博朋克、素材库式商务人物

## AI 资讯

```text
Use case: stylized-concept
Asset type: 知乎专栏正方形封面，1024×1024 PNG
Primary request: 为“AI 资讯”制作一张科技媒体编辑风封面，表达编辑把分散的新消息筛选、核验并整理成清晰结论，而不是泛泛展示“未来科技”。
Scene/backdrop: 明亮、干净的编辑桌面俯视场景；几张无文字的纸质信息卡从四周汇入中央，一枚简洁的透明放大镜压在中央卡片上，少量圆点和连线表示信息来源被核验后汇聚。
Subject: 中央放大镜、三至五张无文字信息卡、清晰的汇聚关系。
Style/medium: 克制的二维编辑插画，带轻微纸张和印刷质感，几何形状简洁，成熟科技媒体气质，不做儿童卡通。
Composition/framing: 正方形构图，核心关系位于中央 60% 安全区；外围元素少而清楚，缩小到 100×100 时仍能一眼看出“信息筛选与核验”。
Lighting/mood: 明亮、理性、可信、清爽。
Color palette: 暖白底，主色为清澈的知性蓝，辅以少量珊瑚橙和石墨灰；避免暗底和高饱和霓虹。
Materials/textures: 哑光纸张、细腻印刷网点、柔和阴影。
Text (verbatim): 不生成任何文字。
Constraints: 与另外两张栏目封面保持相同插画语言、线条粗细、留白和色彩克制度；主体必须适合圆角或轻微裁切。
Avoid: 文字、字母、数字、Logo、水印、二维码、真实新闻截图、伪 UI、乱码、机器人、发光大脑、芯片特写、复杂 HUD、蓝紫霓虹、黑色大背景。
```

## AI 小工具

```text
Use case: stylized-concept
Asset type: 知乎专栏正方形封面，1024×1024 PNG
Primary request: 为“AI 小工具”制作一张清楚、实用的科技媒体编辑插画，表达把一个小而具体的 AI 能力装进工作流程，帮助人快速完成任务；画面要像可操作的工具台，而不是复杂机器。
Scene/backdrop: 明亮的模块化桌面工作台，中央是一枚简洁的多功能旋钮或滑块模块，连接三个易懂的无文字组件：小扳手、裁切框和闪光标记；组件像整齐摆放的实体工具卡，而不是软件截图。
Subject: 中央可操作旋钮、三枚功能组件、清晰而短的连接关系。
Style/medium: 克制的二维编辑插画，带轻微工业设计草图和纸张印刷质感；结构清楚、亲切、实用，不做复杂机械或儿童玩具。
Composition/framing: 正方形构图，工具模块集中在中央 60% 安全区，层级不超过两层；缩小到 100×100 时仍能看出“一个核心工具连接几个具体功能”。
Lighting/mood: 明亮、利落、有动手感，强调可用而不是神秘。
Color palette: 暖白底，主色为清爽青绿色，辅以同系列知性蓝和少量芥末黄；避免暗底和高饱和霓虹。
Materials/textures: 哑光金属、纸卡、柔和投影、细腻印刷网点。
Text (verbatim): 不生成任何文字。
Constraints: 与另外两张栏目封面保持相同插画语言、线条粗细、留白和色彩克制度；图形必须是通用符号，不模仿任何真实产品或品牌界面。
Avoid: 文字、字母、数字、Logo、水印、二维码、真实 App 截图、伪 UI、乱码、复杂齿轮堆叠、机器人、发光大脑、芯片主视觉、HUD、蓝紫霓虹、黑色大背景。
```

## 尺寸核对记录

- 2026-09-23 只读检查知乎公开专栏 API：专栏 `image_url` 当前返回正方形图片。
- 对公开样例的知乎图片派生地址实测为 100×100、200×200、250×250，支持按 1:1 设计。
- 未在无需登录且可访问的知乎官方页面中找到“上传原图推荐像素、最小像素或文件大小”的明确现行说明；1024×1024 PNG 是本项目采用的清晰母版，不冒充知乎官方推荐值。
- 上传后仍需回读裁切、压缩和文件限制；此步骤不包含登录、上传或发布授权。
