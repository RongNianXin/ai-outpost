# AI Outpost 微信公众号申请与接入

## 直接结论

AI Outpost 的核心是每周 AI 资讯和判断，不是支付、会员或客服系统，因此应选 **订阅号**。

- 有本人或团队合法持有的企业/个体工商户主体：优先申请该主体下、可完成微信认证的订阅号。这条路最符合内容定位，也最有机会开放官方草稿与发布接口。
- 没有合法经营主体：申请个人主体订阅号。它可以正常做内容，但自动发布接口可能不可用；本项目会退化为“本机一键生成和复制，后台人工发布”。
- 暂不建议服务号：它更适合交易、会员、查询和客服。除非项目以后转成微信内服务产品，否则不为接口更多而选错账号定位。

腾讯对订阅号的官方定位是信息传播，对服务号的定位是企业业务服务。具体注册材料、认证费用、群发次数和接口权限会调整，以你注册当天的微信公众平台页面为准。

## 申请前准备

- 一个未注册过微信公众平台的邮箱。
- 管理员本人常用微信和身份证。
- 备选名称 2～3 个，例如“AI前哨站”“AI应用前哨站”；名称能否使用以平台校验为准。
- 头像与一句简介。简介建议：`每周筛选真正影响 AI 应用开发者的变化，保留事实、限制和原始来源。`
- 若选企业/个体工商户主体：真实有效的营业执照、主体管理员和平台当页要求的验证材料。不得借用他人主体。

## 注册步骤

1. 操作：打开 [微信公众平台](https://mp.weixin.qq.com/)，点“立即注册”，选择“订阅号”。
   目的：建立适合持续内容发布的公众号。
   预期结果：进入邮箱与主体信息登记流程。
   异常处理：如果页面名称不同或没有订阅号，把当前页面截图发给 AI，不要先选服务号。

2. 操作：完成邮箱验证，然后按真实情况选择“个人”或“企业/个体工商户”主体。
   目的：主体类型会影响认证和接口权限，不能靠后期随意切换。
   预期结果：平台显示你的主体信息和管理员绑定步骤。
   异常处理：缺少企业材料时退回个人订阅号；不要使用不属于你的执照。

3. 操作：用管理员微信扫码，按页面要求完成身份核验，再填写名称、头像和简介。
   目的：完成账号创建。
   预期结果：可以登录公众号后台，并看到“内容与互动”“设置与开发”等菜单。
   异常处理：名称被占用就用备选名；身份或主体审核失败时保存错误码和整页截图。

4. 操作：若使用企业/个体工商户主体，查看“微信认证”入口和当页条件，再决定是否认证。
   目的：本项目要测试官方发布接口，认证通常是关键条件。
   预期结果：后台能明确显示认证状态；认证完成后再检查接口权限。
   异常处理：费用、材料或认证资格以后台当页为准；不要在第三方代办网站付款。

## 创建后需要给 AI 的信息

登录后台后，打开“设置与开发”，把下面两页截图发给 AI：

1. 账号详情：要看账号类型、主体类型、认证状态。
2. 接口权限：要看草稿箱、素材管理、发布能力是否可用。

截图前遮住 AppSecret、手机号、身份证号和其他隐私。只凭“订阅号/服务号”名称不能断言接口可用，最终以这两个后台页面和一次草稿实测为准。

## 接入本机控制页

1. 操作：复制项目根目录的 `.env.example` 为 `.env.local`。
   目的：给本机控制页提供公众号凭据，同时让 Git 忽略真实值。
   预期结果：项目根目录出现 `.env.local`，Git 状态不会显示它。
   异常处理：不确定怎么复制时，让 AI 在本机创建空文件；凭据必须由你本人粘贴。

2. 操作：在公众号后台“设置与开发 > 基本配置”复制 AppID；重置或查看 AppSecret，并只粘贴到 `.env.local` 对应行。
   目的：让本机调用微信官方接口。
   预期结果：重启 `pnpm.cmd publish:console` 后，公众号“凭据已配置”检查变绿。
   异常处理：AppSecret 通常只显示一次；不要把它发到聊天，也不要放进 GitHub。

3. 操作：把本机当前公网 IPv4 加入公众号“IP 白名单”。
   目的：微信会拒绝白名单之外的 access_token 调用。
   预期结果：创建草稿时不再出现 `40164 invalid ip`。
   异常处理：家庭宽带公网 IP 可能变化；看到 40164 时重新查询公网 IP 并更新白名单。

4. 操作：打开 `http://127.0.0.1:3101/`，先点“生成三平台发布包”，再点“创建草稿”，输入页面给出的确认句。
   目的：只把内容送进草稿箱，不直接公开。
   预期结果：公众号后台草稿箱出现本期文章和封面，控制页新增回执。
   异常处理：把错误码和接口权限页截图发给 AI；不要连续重试。

5. 操作：在公众号后台做手机预览，确认标题、封面、段落和来源；通过后再回控制页点“发布文章（非群发）”。
   目的：保留最后一次真实平台预览。
   预期结果：接口返回发布任务编号；文章可能仍处于平台处理或审核中。
   异常处理：个人订阅号或接口受限时，打开控制页“预览公众号稿”，点“复制公众号富文本”，粘贴到公众号编辑器后人工发布。

注意：微信接口中的“发布”会生成公开文章，但不等同于把消息群发给所有关注者。若你希望关注者每周收到推送，需要在账号建好后继续核对“群发”能力；在权限没有确认前，项目不会把“文章已发布”写成“已经群发”。

## 安全边界

- AppSecret 只放 `.env.local`，不发到聊天、不放 GitHub、不写进截图。
- 本机控制页只监听 `127.0.0.1`；关闭终端后入口停止。
- 草稿与正式发布分成两个按钮；重复内容有本地回执，默认阻止再次发送。
- 微信接口、审核和群发规则可能变化；账号建好后必须以实际后台权限和一次草稿测试复核。
