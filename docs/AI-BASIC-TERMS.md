# AI 基础概念库

## 用途

这是 AI 前哨站的基础术语单一来源。库内词默认视为目标读者已经知道的入门概念：正文和“术语解释”区都不重复解释。基础词可以正常使用，但不能借基础词掩盖一个产品的特殊含义、权限条件或新的技术用法。

这不是“所有读者都懂”的证明，也不是词典。名单保持保守；出现争议时宁可暂不入库，也不要用读者不懂的词替代白话表达。

## 首版基础词

| 词 | 适用范围 | 例外 |
| --- | --- | --- |
| 人工智能 / AI | 泛指用计算机完成通常需要人判断的任务 | 文章讨论某种新型 AI 架构时，解释新架构，不解释 AI 本身 |
| 模型 | 经过训练、可对输入产生输出的计算系统 | 产品名中的特殊“模型”含义、版本差异或评测口径仍需说明 |
| 大模型 | 参数规模较大、可处理多种任务的模型 | 某厂商给“大模型”附加特殊能力或范围时，解释该附加含义 |
| 提示词 | 给模型的指令或输入要求 | 专门的提示词格式、协议或安全绕过方法仍需说明 |
| 上下文 | 模型在当前任务中可参考的输入和历史信息 | 上下文窗口、压缩、截断、缓存等会改变结果时，解释具体条件 |
| Agent | 能根据目标连续调用工具或执行多步任务的 AI 系统 | 某产品的权限、身份、回滚或自主执行范围仍需说明 |
| API | 让程序按约定调用另一项服务的接口 | 具体 endpoint、认证、配额和计费仍需说明 |
| token | 模型处理文本时使用的计量单位；价格按 token 计费时要写清输入、输出和缓存口径 | 不同模型的切分方式和计费规则不同，不能把 token 当成字数 |
| GA | Generally Available，通常表示功能进入正式可用阶段 | 仍需核对套餐、地区、版本和接口限制 |
| Beta | 公开测试阶段，功能、范围和规则仍可能调整 | 不能把 Beta 写成稳定生产能力 |

## 解释位置规则

1. **新产品先判断新旧。** 产品名、功能名和专有协议不因含有基础词而自动入库。若公开传播不超过约 1 个月，在正文第一次出现处用一句话说明；若已传播约 1–3 个月且正文不需要停下来解释，可放入术语区。两处不同时解释。
2. **时间是编辑判断，不是自动证明。** “传播”须有至少两个独立、可回读的公开使用信号和日期；没有术语首次公开日期或传播证据时按 0–1 个月的新词处理，不能声称完成全网统计。
3. **超过约 3 个月也不自动免解释。** 如果词在本期语境有新义、权限含义或容易和旧产品混淆，仍在正文解释一次；基础库只管普通入门含义。
4. **术语区不凑数。** 新期术语区先与前两期 `glossary` 回读去重；没有必要解释的词就留空。相同词只有在含义发生实质变化时才重新出现，并写清变化。
5. **正文优先保证事实理解。** 术语解释不能替代“发生了什么、谁能用、有什么影响和限制”的正文说明。
