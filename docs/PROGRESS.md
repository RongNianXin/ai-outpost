### V1.2 情报卡减压精修

- 采纳多 AI 审查意见中“降低阅读压力”的方向，将情报卡默认视图压缩为标题、结论、开发者影响、为什么重要和行动建议。
- 将“事实支撑验证”“技术限制”和“官方来源链接”收入原生 `<details>` 折叠区，默认不展开；用户需要核实时再点击“[ 展开技术实据与来源 ]”。
- 页面可见标签收敛为两个刚性维度：`策略建议` 和 `技术风险`；`maturity` 与 `noiseRisk` 字段继续保留在底层 JSON 和公众号导出中，但不在网页卡片首屏外露。
- 手机端情报卡头部改为单列阅读流：标题置顶，编号、分类、发布方和日期在标题下方换行排列，避免 375-430px 宽度下拥挤。
- 拒绝将 JSON 字段强行改名为 `headline`、`oneSentence`、`fact`、`source`、`scriptLine`；当前 schema 已有等价字段映射：`title`、`oneLineSummary`、`facts`、`sources`、`communicationAngle`。重命名会破坏现有校验、导出和测试。
- 拒绝照搬“情报卡 01（OpenAI 内容审核）”提示，因为当前第 001 期已经覆盖为 2026-06-17 版本，卡片 01 是 GitHub Agentic Workflows。实践闭环继续绑定当前 `practiceTask.relatedCardIds`。
- 修复实践区锚点心智不一致问题：目标区域现在显式显示“本周实践”作为卡片标题，具体任务名降级为副标题。
- 修正策略标签可理解性：将“学习 / 验证 / 跟进”改为“先学习 / 动手试一下 / 持续关注”，并在卡片内补充一句人话解释，降低新用户理解成本。
