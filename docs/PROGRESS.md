## 2026-06-16

### 已确认

- 本地预览统一使用 `http://127.0.0.1:3100/`，避免和其它本地项目的 localhost 端口冲突。
- 视觉方向采用“现代情报控制台”，优先解决文字突兀、层级不清和页面不够美观的问题。

### 已完成

- 将首页和期刊详情页改为控制台式视觉：渐变首屏、概览面板、重点变化卡片、情报卡状态标签和来源面板。
- 将归档页和关于页同步到同一视觉系统，避免页面之间风格断裂。
- 保持内容结构、审核流程、发布闸门、微信公众号导出逻辑不变。
- 使用应用内浏览器检查 3100 预览页；窄屏与 390px 移动视口无横向溢出，浏览器控制台无错误。
- 通过 `typecheck`、`lint`、`test`、`build`、`content:validate` 和 `content:export:wechat`。
- 本地 HTTP 检查首页、归档、关于和第 001 期详情页均返回 200。

### 风险

- 应用内浏览器截图接口偶发超时，因此本轮以 DOM 尺寸、控制台日志和本地 HTTP 检查作为自动验收依据。
- 生产构建仍不会公开第 001 期正式 slug，这是发布闸门的预期行为；公开发布前仍需明确批准。

### 下一步

- 发布者人工查看 3100 预览页面，确认“现代情报控制台”方向是否可接受。
- 若视觉方向确认，保存一个 Git 版本，建议提交说明为 `feat: refresh UI as intelligence console`。
- 公开发布前再决定是否填写最终发布时间并运行 GitHub Pages 部署流程。
