# AI 前哨站 GitHub 首页展示图提示词

这是一份给网页版 ChatGPT 使用的可复制提示词。它只负责生成仓库首页的背景展示图；期号、长标题和链接由 README 的确定性文字排版承载，避免生图模型生成难以校对的长中文。

```text
请使用当前可用的最新 Image 2.5 生图模型（如果界面没有该模型，请明确告知实际使用的模型，不要伪称版本），为 GitHub 仓库「AI 前哨站 / AI Outpost」生成一张原创首页展示图。

项目主题：这是一个面向 AI 应用创造者的低维护情报周报与内容生产工作流。它从官方来源筛选少量 AI 产品、模型、Agent 协作和权限变化，整理成“发生了什么—造成什么影响—有哪些限制—来源在哪里”的可核对内容，并生成官网和微信公众号稿件。

画面目标：让第一次打开 GitHub 仓库的人立刻感到这是成熟、克制、重视证据的科技媒体与工程项目；画面要有编辑部/新闻简报的秩序感，但不要像广告海报或泛化的 AI 宣传图。

构图：宽幅 16:9，建议 1600×900 或更高分辨率；左侧和上方保留足够干净的负空间，方便 README 后续叠放标题；右侧安排 2—3 个弱化的抽象内容卡片、来源索引线、时间节点或核验标记，表达“筛选、核验、解释影响”的关系。层次从前景到背景清楚，缩小到 GitHub 页面和手机宽度后仍然稳定。

视觉方向：深色编辑台/新闻简报感，底色为石墨黑、深海军蓝或雾灰黑；大面积留白使用深浅关系而不是噪点；仅用少量青色与琥珀色作为状态点缀。可以有细网格、纸张/卡片边缘、轻微扫描线或编辑标记，但都要克制、低对比、服务于信息层级。

必须遵守：
1. 画面原创，不复制任何现有媒体封面、GitHub 仓库封面或新闻截图的独特构图。
2. 不生成任何文字、数字、期号、Logo、品牌名称、产品名称、网址、水印或伪造的引用；也不要生成可被误认成真实产品界面的具体 UI。
3. 不使用机器人头像、发光大脑、机房、云数据流、赛博城市、复杂 HUD、霓虹蓝紫、荧光渐变、粉色主调或高饱和光效。
4. 不画真实人物、名人、公司商标或未经授权的产品截图，不暗示任何 AI 公司官方背书。
5. 不把“AI 自动完成”“绝对可靠”“完全离线”等能力画成已经成立的事实；只表达内容筛选、来源核对和人工判断这些关系。
6. 不用过度复杂的微小细节填满画面，不让背景抢过 README 标题和入口链接。

请输出 3 个风格接近但构图不同的候选版本，并为每个版本说明：核心视觉关系、适合放在 README 的原因、可能造成的误读。优先给出可直接用于网页的 PNG 或高质量 JPG；如果生成结果包含了错误文字、伪 Logo、真实产品 UI 或过度艳丽的色彩，请主动标记并重新生成。
```

## 收图后的本地验收

拿到成图后，先不要直接推送。检查以下项目：

1. 图片尺寸和比例适合 GitHub README 首屏，左侧标题安全区没有高对比细节。
2. 没有错误文字、伪造 Logo、真实产品截图或无法解释的数字。
3. 深色、青色和琥珀色只是克制点缀，没有偏粉或霓虹效果。
4. 图片表达的是“筛选—核验—解释影响”，而不是“模型万能”或“自动发布”。
5. 在 README 实际渲染宽度下仍能看清入口和标题，并保留 AI 生成示意标识（如用于文章或其他平台）。

确认后再把图片保存为 `assets/repository-cover.png`（或当期确定的文件名），补入 README 首屏，并重新运行链接、隐私、Markdown 和 Git 差异检查。
